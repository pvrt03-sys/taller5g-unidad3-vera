## Descripción
Este repositorio contiene la resolución de la tarea práctica sobre algoritmos de conversión por rastreo. La entrega consta de dos ejercicios implementados en Python utilizando la biblioteca Pillow:
Ejercicio 1: Composición geométrica (casa) construida utilizando exclusivamente el algoritmo DDA.
Ejercicio 2: Generación de rosetas geométricas paramétricas aplicando el algoritmo de Bresenham generalizado y cálculos trigonométricos.

## Archivos incluidos
* `ejercicio1_casa.py` - Código fuente del Ejercicio 1.
* `ejercicio2_roseta.py` - Código fuente del Ejercicio 2.
* `casa.png` - Imagen generada por el Ejercicio 1.
* `roseta_12.png`, `roseta_24.png`, `roseta_36.png` - Imágenes generadas por el Ejercicio 2.
